# Security Policy

[English](#english) | [简体中文](#简体中文)

## English

Please do not disclose suspected vulnerabilities in public issues or discussions.

Use the repository's **Security** tab, open **Advisories**, and select **Report a vulnerability**.
Include the affected version, deployment mode, reproduction steps, impact, and any suggested fix.
Remove credentials, private workspace content, and personal data from the report.

Only the latest release and the current `main` branch receive security fixes. Maintainers will
acknowledge a report as soon as practical, validate the issue, coordinate a fix, and publish an
advisory when affected users can upgrade safely. Please allow time for remediation before public
disclosure.

Deployment hardening guidance is available in [docs/security.md](docs/security.md).

## 简体中文

请勿在公开 Issue 或 Discussion 中披露疑似安全漏洞。

请打开仓库的 **Security** 页面，进入 **Advisories**，选择 **Report a vulnerability** 进行私密报告。报告中请包含受影响版本、部署方式、复现步骤、影响和建议修复方案，并移除凭证、工作台私密内容和个人数据。

项目仅为最新发布版本和当前 `main` 分支提供安全修复。维护者会尽快确认报告、验证问题、协调修复，并在受影响用户可以安全升级后发布公告。公开披露前请预留合理的修复时间。

部署加固建议见 [docs/security.md](docs/security.md)。
